# @babel/plugin-proposal-structs

> Transform structs proposal (non-shared structs)

See our website [@babel/plugin-proposal-structs](https://babeljs.io/docs/babel-plugin-proposal-structs) for more information.

## Install

Using npm:

```sh
npm install --save-dev @babel/plugin-proposal-structs
```

or using yarn:

```sh
yarn add @babel/plugin-proposal-structs --dev
```
