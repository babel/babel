# @babel/helper-named-evaluation

> Helper to preserve or prevent the NamedEvaluation of anonymous functions and classes

See our website [@babel/helper-named-evaluation](https://babeljs.io/docs/babel-helper-named-evaluation) for more information.

## Install

Using npm:

```sh
npm install --save @babel/helper-named-evaluation
```

or using yarn:

```sh
yarn add @babel/helper-named-evaluation
```
