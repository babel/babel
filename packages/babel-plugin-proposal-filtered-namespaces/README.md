# @babel/plugin-proposal-filtered-namespaces

> Transform filtered namespace imports (`import { a, b } as ns from "mod"`) and the `exports` option of dynamic import

See our website [@babel/plugin-proposal-filtered-namespaces](https://babeljs.io/docs/babel-plugin-proposal-filtered-namespaces) for more information.

## Install

Using npm:

```sh
npm install --save-dev @babel/plugin-proposal-filtered-namespaces
```

or using yarn:

```sh
yarn add @babel/plugin-proposal-filtered-namespaces --dev
```
